# API пилота

API обслуживается тем же доменом, что и веб-приложение, по пути `/api`. Исходное видео, изображения и координаты скелета не передаются ни в одном запросе.

## Публичные маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/api/health` | Проверка доступности после публикации. |
| `GET` | `/api/policy` | Политика данных и правило лидерборда. |
| `GET` | `/api/challenges` | Активные челленджи. |
| `GET` | `/api/challenges/:id/leaderboard` | Только вручную подтверждённые результаты и рейтинг команд. |
| `POST` | `/api/participants` | Создаёт псевдоним и выдаёт случайный токен участника. Токен хранится только в браузере. |
| `POST` | `/api/challenges/:id/submissions` | Отправляет числовой итог приседаний. Требует токен участника. |

Сервер заново рассчитывает итоговый балл из попыток и качества; клиентский балл не принимается на веру. На один челлендж у участника возможна одна отправка. Все отправки создаются в статусе `pending`; публичный рейтинг выбирает только `verified`.

## Маршруты организатора

Сессия создаётся `POST /api/admin/session` по значениям из защищённого файла окружения. Токен действует 8 часов и сохраняется в `sessionStorage`, не в постоянном хранилище браузера.

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/api/admin/summary` | Агрегированные показатели пилота. |
| `GET` | `/api/admin/submissions?status=pending` | Очередь проверки. |
| `PATCH` | `/api/admin/submissions/:id` | Подтверждает или отклоняет результат. |
| `POST` | `/api/admin/challenges` | Создаёт черновик или публикует челлендж. |
| `POST` | `/api/admin/protocols` | Добавляет новую неизменяемую версию правил приседания. |
| `GET`, `POST` | `/api/admin/teams` | Просмотр и создание команд. |
| `GET` | `/api/admin/participants` | Список псевдонимов без видео и персональных данных. |
| `PATCH` | `/api/admin/participants/:id/team` | Назначает команду. |
| `DELETE` | `/api/admin/participants/:id` | Удаляет псевдоним и связанные результаты. |
| `GET` | `/api/admin/export` | Выгружает агрегируемые строки в CSV. |

## Ограничения честности

Проверка организатором — осознанный минимальный антифрод для закрытого пилота. Она не доказывает, что числовые показатели нельзя подделать, поэтому лидерборд не должен использоваться для призов или формальной аттестации до отдельного проектирования защиты. Любое изменение порогов создаётся отдельной версией протокола и не переписывает уже полученные результаты.
