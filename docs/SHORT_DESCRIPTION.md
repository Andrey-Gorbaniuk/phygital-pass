# Краткое описание проекта

**Phygital Pass** — веб-сервис для университетских спортивных челленджей на базе компьютерного зрения. Через камеру смартфона или ноутбука он локально распознаёт позу, по прозрачным правилам проверяет выполнение упражнения и формирует цифровой фиджитал-паспорт результата. В первом рабочем сценарии пользователь выполняет 10 приседаний, видит скелетную модель и обратную связь в реальном времени, а после теста получает балл и измеримые показатели; организатор может проводить челленджи и публиковать в рейтинге только подтверждённые результаты. Видео не отправляется на сервер: для челленджа сохраняются только необходимые числовые данные и псевдоним участника.
