# Phygital Pass

Веб-сервис для цифровых спортивных челленджей в университете. По видео с камеры смартфона он распознаёт позу, проверяет выполнение упражнения, считает корректные повторения и формирует индивидуальный фиджитал-паспорт студента.

Первая версия доказывает один законченный сценарий: **камера → 10 приседаний → проверенный результат → фиджитал-паспорт**.

## Статус

Есть рабочее локальное демо: камера, распознавание позы, тест из 10 приседаний и локальный фиджитал-паспорт. Перед пилотом остаётся калибровка порогов на реальных прохождениях.

## Быстрый запуск

Требуется Node.js 20.19 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite, в Chrome или Safari, разрешите доступ к камере и встаньте в кадр целиком. Камера работает на `localhost` во время разработки и по HTTPS после публикации.

## Публикация

Конфигурация Cloudflare Workers уже добавлена. После входа в нужный аккаунт Cloudflare:

```bash
npm run deploy
```

Приложение разворачивается как статический сайт; сервер, база данных и хранение видео не используются.
