# Phygital Pass

Веб-сервис для цифровых спортивных челленджей в университете. По видео с камеры смартфона он распознаёт позу, проверяет выполнение упражнения, считает корректные повторения и формирует индивидуальный фиджитал-паспорт студента.

Первая версия доказывает один законченный сценарий: **камера → 10 приседаний → проверенный результат → фиджитал-паспорт**.

## Статус

Есть рабочий пилотный контур: камера и тест приседаний, локальная история, карточка результата, челленджи, проверяемый лидерборд и кабинет организатора. Перед запуском с участниками обязательна калибровка порогов на реальных прохождениях.

## Быстрый запуск

Требуется Node.js 20.19 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite, в Chrome или Safari, разрешите доступ к камере и встаньте в кадр целиком. Камера работает на `localhost` во время разработки и по HTTPS после публикации.

## Публикация

Проект разворачивается на собственном VPS через Docker Compose: приложение, PostgreSQL и Caddy. База данных не доступна из интернета; Caddy выпускает и продлевает HTTPS-сертификат автоматически.

До первого запуска:

1. Создайте DNS-запись `A` для домена на IP VPS и откройте на сервере только TCP-порты 80 и 443.
2. Установите Docker Engine с Docker Compose plugin, склонируйте репозиторий на сервер.
3. Создайте секретный файл и заполните реальные значения — не добавляйте его в Git:

```bash
cp deploy/.env.example deploy/.env
```

`ORGANIZER_PASSWORD` должен отличаться от пароля базы, а `SESSION_SECRET` — быть случайной строкой не короче 32 символов.

Первый запуск и обновление:

```bash
npm run deploy:vps
curl -fsS https://ваш-домен/api/health
```

При первом запуске контейнер `migrate` применяет схему PostgreSQL. Повторный запуск безопасен: текущая миграция идемпотентна. Для обновления кода выполните `git pull` и снова `npm run deploy:vps`.

Исходное видео и кадры не отправляются на сервер. Сервер хранит только псевдоним, выбранную команду, числовые показатели результата и статус ручной проверки. В лидерборд попадают только результаты со статусом «подтверждён».

### Резервная копия базы

На VPS периодически сохраняйте дамп вне контейнера:

```bash
docker compose --env-file deploy/.env -f deploy/docker-compose.yml exec -T database \
  pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB" > phygital-pass-backup.sql
```

Перед выполнением команды убедитесь, что переменные `POSTGRES_USER` и `POSTGRES_DB` заданы в оболочке или подставьте их реальные значения.
